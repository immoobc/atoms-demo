# Atoms 控制台复刻 · 设计规范

## Direction & Layout
- 目标：高还原复刻 atoms.dev/zh/dashboard（登录后控制台）。原页面需要登录，视觉以公开首页为准（白底、近黑主按钮、Agent 头像、大号提示词输入框），控制台结构按 Atoms 常见形态推断。
- 气质：干净、克制、以“输入想法 → 生成应用”为唯一焦点。不要深色赛博风，不要渐变边框卡片。
- 首屏标志：居中大标题“把想法变成可销售的产品”（“产品”用紫色渐变文字）+ 头像组 + 大号圆角输入框。
- 布局：左侧固定侧边栏 248px（可折叠为 64px）+ 右侧主区；主区内容最大宽度 1120px，输入框最大宽度 760px。
- 主区顺序：顶栏（右侧邀请/通知/升级）→ Hero 输入区 → 推荐提示词标签 → 项目区（标签页 + 搜索 + 排序 + 视图切换 + 卡片网格）。
- 网格：桌面 4 列，平板 2–3 列，手机 1 列，卡片间距 20px，区块间距 56px。
- 响应式：<1024px 侧边栏隐藏，由顶栏菜单按钮打开抽屉（Sheet）。
- Do：大量留白、细灰边框、黑色主按钮。Don't：彩色左边框卡片、大面积紫色、玻璃拟态。

## Tokens
- 颜色：背景 #FFFFFF；侧边栏 #F7F7F8；表面悬浮 #F2F2F4；边框 #E7E7EA；主文字 #0B0B0F；次文字 #5B5B66；弱文字 #9A9AA5；主按钮 #0B0B0F 文字白；强调紫 #7C5CFF（仅用于“产品”渐变 #7C5CFF→#C25BFF、积分进度条、选中指示）；成功 #16A34A；危险 #DC2626。
- 字体：Plus Jakarta Sans + "PingFang SC","Noto Sans SC" 回退。Hero 标题 44/52 700；区块标题 18/26 600；正文 14/22 400；按钮 14 500；说明 12/18。
- 间距：4/8/12/16/20/24/32/56。圆角：按钮 10px，输入框外壳 20px，卡片 14px，缩略图 10px，图标按钮 8px 方形，头像圆形。
- 层级：卡片 1px #E7E7EA 边框，悬浮阴影 0 8px 24px rgba(15,15,20,.08)；输入框阴影 0 4px 24px rgba(15,15,20,.06)；弹层使用 shadcn 默认。

## Shared Patterns & States
- 侧边栏导航项：高 36px，圆角 8px，悬浮 #ECECEF，选中白底+细边框。
- 提示词输入框：空内容时发送按钮禁用（灰），有内容为黑色；Enter 发送、Shift+Enter 换行；附件以标签展示可移除。
- 项目卡片：16:10 缩略图 + 名称 + 更新时间；悬浮显示收藏与更多菜单；支持重命名、复制、删除。
- 空状态：图标 + 一句说明。
- 动效：150ms ease-out 颜色/阴影过渡，卡片悬浮上移 2px；不对主内容做入场隐藏。
- 无障碍：图标按钮均有 aria-label，焦点环 2px #7C5CFF，点击区 ≥ 32px。

## Media
- Agent 头像与项目缩略图复用 Atoms 公开 CDN 图片（首页同款）；其余缩略图使用柔和渐变占位并叠加项目首字，属可接受替代。
